# Recursos visuales

## Objetivo

La interfaz de inicio de sesión de Diplomatic Fleet utiliza una identidad visual denominada **Diplomatic Noir**.

El diseño combina alto contraste, formas diagonales, texturas de semitono y composición gráfica inspirada en interfaces de cómic. La identidad fue adaptada al contexto de movilidad institucional y alquiler de vehículos diplomáticos.

## Paleta de colores

- Negro principal: `#09090C`
- Gris oscuro: `#1A1A1E`
- Rojo principal: `#C8102E`
- Rojo oscuro: `#8F0A1F`
- Rojo claro: `#E02B48`
- Blanco: `#FFFFFF`
- Papel claro: `#F4F0E8`

## Tipografías

La interfaz utiliza las siguientes tipografías:

- **Anton:** títulos principales y elementos destacados.
- **Archivo:** formularios, textos descriptivos y contenido general.

Las tipografías se cargan mediante Google Fonts.

## Sedán ejecutivo

Archivo:

`src/main/resources/static/assets/images/diplomatic-sedan.png`

El sedán ejecutivo fue generado específicamente para este proyecto mediante Microsoft Copilot.

Características:

- Fondo transparente.
- Sin logotipos comerciales.
- Sin marcas reconocibles.
- Uso exclusivo como recurso decorativo del proyecto académico.
- Representa el servicio de movilidad institucional ofrecido por Diplomatic Fleet.

## Recursos creados con CSS

Los siguientes elementos no dependen de imágenes externas:

- Textura de semitono.
- Formas diagonales.
- Franjas inferiores.
- Silueta institucional.
- Bordes y sombras rígidas.
- Fondo rojo, negro y blanco.
- Sello de demostración académica.
- Estados visuales de campos y botones.

## Propiedad intelectual

La interfaz no utiliza personajes, logotipos, capturas, iconos ni recursos extraídos de videojuegos.

La composición toma como referencia general las interfaces gráficas de cómic y utiliza una identidad propia para Diplomatic Fleet.

## Uso académico

Los recursos descritos en este documento forman parte de una demostración académica.

No deben reutilizarse como representación de una institución diplomática real ni como material oficial de una entidad gubernamental.
