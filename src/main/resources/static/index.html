Términos de uso

Diplomatic Fleet es una aplicación académica creada para demostrar procesos de gestión de servicios vehiculares institucionales.

Uso autorizado

El acceso está limitado a personas autorizadas por el equipo responsable del proyecto.

Datos de demostración

Durante las pruebas deben utilizarse datos ficticios. No se deben registrar contraseñas reales, documentos de identidad ni información institucional confidencial.

Alcance

La demo guarda datos en el almacenamiento local del navegador y no garantiza disponibilidad ni conservación de la información.

Política de privacidad

Los datos introducidos se utilizan únicamente para demostrar las funcionalidades académicas del sistema.

Credenciales

Las contraseñas no se almacenan en texto plano y deben protegerse en el backend mediante un algoritmo seguro (BCrypt).

Información personal

No deben utilizarse datos personales reales sin autorización expresa. Puede borrar los datos de la demo limpiando el almacenamiento del sitio.
